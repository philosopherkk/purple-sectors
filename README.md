# Purple Sectors

Weekly iRacing board: popular races, favourite series (Porsche Cup, Ring Meister), track history, car dossiers.

## Live site (after one click)

https://philosopherkk.github.io/purple-sectors/

Turn Pages on:

1. Open **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main` / folder `/ (root)`
4. Save. Wait one minute.

Then open that URL on iPhone Safari. Add to Home Screen for the purple icon.

Opening a downloaded `.html` from Files uses `file://` and Safari blocks maps and YouTube. HTTPS fixes that.
